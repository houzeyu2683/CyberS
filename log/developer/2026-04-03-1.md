## 實作細節

### `project/kits/analyzer.py`
- 移除 `import anthropic`
- 加入 `import yaml`、`import sys`、`import google.generativeai`
- 模組載入時讀取 `key.yaml`，呼叫 `sys.modules["google.generativeai"].configure(api_key=...)`
- 將 `call_claude(prompt)` 改為 `call_llm(prompt, system_prompt)`
- **關鍵設計**：
  - `call_llm` 內部每次呼叫時從 `sys.modules["google.generativeai"]` 取 genai，而非使用 module-level 變數
  - 原因 1：`google` 為 namespace package，`import X as name` 經由 parent 屬性解析，`patch.dict(sys.modules)` 無法攔截，從 `sys.modules` 直接取值才能讓測試的 mock 正確注入
  - 原因 2：unit tests 執行 reload 後 module-level 變數會殘留 MagicMock，在 `call_llm` 內部取值可確保 `patch.dict` 退出後自動還原真實 genai，integration test 不受影響
- 使用 `genai.GenerativeModel(model_name="gemini-2.5-flash", system_instruction=system_prompt)`
- `gemini-2.5-flash` 回傳 markdown 包裝的 JSON（` ```json...``` `），在 `json.loads` 前用 regex 剝除
- `analyze_cve` 呼叫改為 `call_llm(prompt, SYSTEM_PROMPT)`

### `project/app.py`（新增）
