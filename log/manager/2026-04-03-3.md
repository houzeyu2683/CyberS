## 任務二：新增 `kits/threat.py`

### 功能規格

#### `check_poc(cve_id: str) -> dict`
- 呼叫 GitHub Search API：
  `GET https://api.github.com/search/repositories?q={cve_id}`
- 從 `key.yaml` 讀取 `GITHUB_TOKEN`（選填），有則加入 Authorization header
- 回傳：
  ```python
  {"has_poc": True, "poc_count": 12}
  ```
- `total_count > 0` → `has_poc: True`

#### `check_kev(cve_id: str) -> dict`
- 即時下載 CISA KEV JSON：
  `GET https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json`
- 比對 `cveID` 欄位是否包含該 CVE ID
- 回傳：
  ```python
  {"in_the_wild": True}
  ```

### 測試重點
- `check_poc("CVE-2021-44228")` → `has_poc: True`，`poc_count > 0`
- `check_poc("CVE-9999-99999")` → `has_poc: False`，`poc_count: 0`
- `check_kev("CVE-2021-44228")` → `in_the_wild: True`（Log4Shell 在 KEV 清單中）
- `check_kev("CVE-9999-99999")` → `in_the_wild: False`
- GitHub API 連線失敗時拋出 `ConnectionError`
- CISA KEV 連線失敗時拋出 `ConnectionError`

## 任務三：更新 `kits/reporter.py`

### 變更說明
- `generate_report` 新增兩個參數：
  ```python
  def generate_report(
      cve_id: str,
      check_poc: bool = False,
      check_kev: bool = False,
  ) -> dict:
  ```
- 邏輯：
  ```python
  threat_intel = {}
  if check_poc:
      threat_intel.update(check_poc_fn(cve_id))
  if check_kev:
      threat_intel.update(check_kev_fn(cve_id))
  if threat_intel:
      report["threat_intel"] = threat_intel
  ```
- 兩個都未勾選時，報告不含 `threat_intel` 欄位

### 輸出範例（兩個都勾選）
```json
{
  "cve_id": "CVE-2021-44228",
  "summary": "...",
  "impact": {...},
  "recommendations": {...},
  "risk_rating": "Critical",
  "threat_intel": {
    "has_poc": true,
    "poc_count": 12,
    "in_the_wild": true
  },
  "generated_at": "2026-04-03T12:00:00"
}
```

### 測試重點
- `check_poc=False, check_kev=False` → 報告無 `threat_intel` 欄位
- `check_poc=True, check_kev=False` → 報告含 `threat_intel.has_poc`，無 `in_the_wild`
- `check_poc=False, check_kev=True` → 報告含 `threat_intel.in_the_wild`，無 `has_poc`
- `check_poc=True, check_kev=True` → 報告含完整 `threat_intel`
