## 功能一規格：EPSS

### 背景
EPSS（Exploit Prediction Scoring System）由 FIRST 組織維護，提供 CVE 未來 30 天被利用的機率預測，與現有 PoC、KEV 形成三維威脅評估。

### 1. `project/kits/threat.py` — 新增 `check_epss()`

**函式簽名**：
```python
def check_epss(cve_id: str) -> dict:
```

**API**：`https://api.first.org/data/1.0/epss?cve={cve_id}`

**成功回傳**（找到資料時）：
```python
{
    "epss_score": 0.0342,
    "epss_percentile": 0.892,
    "epss_high_risk": True/False  # score > 0.1 時為 True
}
```

**失敗回傳**（查無資料或任何例外）：
```python
{
    "epss_score": None,
    "epss_percentile": None,
    "epss_high_risk": False,
    "epss_note": "無資料"
}
```

**高風險門檻**：`epss_score > 0.1`，函式需捕捉所有例外，不得往外拋。

## 功能二規格：Markdown 報告產生

### 使用流程
1. 使用者輸入 CVE ID + 勾選項目 → 按「分析」→ 顯示 JSON
2. 看完 JSON 後 → 按「**產生 Markdown 報告**」→ 顯示渲染結果 + 下載按鈕

### 1. `project/kits/reporter.py` — 新增 `report_to_markdown()`

**函式簽名**：
```python
def report_to_markdown(report: dict) -> str:
```

**輸出格式**：
```markdown
# CVE 漏洞分析報告

## 基本資訊
- **CVE ID**: {cve_id}
- **風險評級**: {risk_rating}
- **優先級**: {recommendations.priority}
- **產生時間**: {generated_at}

## 漏洞摘要
{summary}

## 影響分析
- **影響摘要**: {impact.impact_summary}
- **攻擊向量**: {impact.attack_vector}
- **攻擊條件**: {impact.attack_conditions}
- **嚴重性**: {impact.severity_label}
- **可利用性**: {impact.exploitability}
- **受影響元件**:
  - {element1}
  - {element2}

## 修復建議
### 修補行動
1. {patch_action_1}

### 暫時緩解措施
1. {workaround_1}

## 威脅情報
（僅在 threat_intel 存在時顯示此區塊）

| 指標 | 狀態 |
|------|------|
| PoC 公開 | 是（N 個倉庫）/ 否 |
| In the Wild（CISA KEV） | 是 / 否 |
| EPSS 分數 | {score}（百分位：{percentile}）⚠️ 高風險 / 正常 |

（若 epss_warning 存在）
> ⚠️ {epss_warning}
```

**注意**：`threat_intel` 不存在時，整個「威脅情報」區塊不顯示。

### 2. `project/app.py` — 新增 Markdown 報告 UI

**新增函式**：
```python
def to_markdown(report_json):
    if not report_json or "error" in report_json:
        return "尚無報告，請先執行分析。", gr.update(visible=False)
    md_text = report_to_markdown(report_json)
    # 將 md_text 寫入暫存檔 report.md，回傳路徑供下載
    path = "/tmp/cve_report.md"
    with open(path, "w", encoding="utf-8") as f:
        f.write(md_text)
    return md_text, gr.update(value=path, visible=True)
```

**新增 UI 元件**：
```python
md_btn = gr.Button("產生 Markdown 報告")
md_out = gr.Markdown()
dl_btn = gr.DownloadButton(label="下載 .md 報告", visible=False)
md_btn.click(fn=to_markdown, inputs=[out], outputs=[md_out, dl_btn])
```
