  def call_llm(prompt: str, system_prompt: str) -> dict:

## 任務二：新增 `app.py`（含中文說明區塊）

### 檔案位置
`project/app.py`

### 功能規格
- Gradio Blocks UI
- 說明區塊：輸入框上方放 `gr.Markdown`，中文說明專案用途與使用流程，內容如下：
  ```
  ## CVE 自動分析系統

  **專案用途**
  輸入 CVE ID，系統自動從 NVD、OSV.dev、GitHub Advisory 擷取漏洞資訊，
  透過 AI 分析影響範圍與攻擊向量，並生成具體的修復建議。

  **使用流程**
  1. 在下方輸入框填入 CVE ID（例：CVE-2021-44228）
  2. 點擊「分析」按鈕
  3. 查看右側 JSON 報告，包含漏洞摘要、影響分析、修復建議與風險評級
  ```
- 輸入：`gr.Textbox`（label="CVE ID"，placeholder="CVE-2021-44228"）
- 按鈕：「分析」
- 輸出：`gr.JSON`（顯示 `generate_report(cve_id)` 回傳的完整 dict）
- 錯誤處理：任何 exception 捕捉後回傳 `{"error": str(e)}`

### 核心邏輯
```python
from kits.reporter import generate_report

def analyze(cve_id: str):
    try:
        return generate_report(cve_id)
    except Exception as e:
        return {"error": str(e)}
```

### 測試重點
- 輸入合法 CVE ID（如 CVE-2021-44228）→ 回傳包含 cve_id、summary、impact、recommendations、risk_rating 的 dict
- 輸入非法格式（如 "abc"）→ 回傳 `{"error": "..."}`
- 輸入空字串 → 回傳 `{"error": "..."}`
